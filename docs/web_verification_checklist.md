# Phase 1 마감 전 웹 전체 점검 체크리스트

`docs/web_export.md`의 절차대로 export → `F:/Godot/web_build` → 정적 서버로
서빙해서 확인한다(에디터의 "브라우저에서 실행"은 쓰지 않는다). 문제를
발견하면 어떤 항목에서, 어떤 브라우저/콘솔 로그와 함께 났는지 메모해두면
고칠 때 빠르다.

## 이미 확인 끝남 (다시 안 해도 됨)
- 웹 export 절차/설정
- FilePicker 웹 동작
- user:// 저장이 새로고침 후에도 유지됨
- 한글 폰트
- 게임 한 판 끝까지(효과음, 특수 족보 연출 포함)

## 캐릭터 편집 화면 (1-6)
- [ ] 캐릭터 새로 만들기가 된다
- [ ] 캐릭터 복제가 된다
- [ ] 캐릭터 삭제가 된다
- [ ] 스탠딩 이미지 업로드가 된다
- [ ] 썸네일 업로드가 된다
- [ ] 보이스 매핑에서 파일 추가가 된다(웹은 한 번에 1개만 - 여러 이벤트에
      각각 추가해서 확인)
- [ ] 보이스 미리듣기가 재생된다
- [ ] 볼륨 슬라이더를 움직이면 재생 중인 미리듣기 음량이 바로 바뀐다
- [ ] 저장 안 하고 다른 캐릭터를 선택/닫기를 누르면 "저장 안 한 변경사항"
      확인 대화상자가 뜬다
- [ ] 만든 캐릭터가 게임 시작 전 캐릭터 선택 화면에 나오고, 골라서 게임에
      들어가면 실제로 반영된다(초상/이름/보이스)

## 캐릭터 팩 (1-7)
- [ ] [내보내기]를 누르면 브라우저 다운로드가 실제로 시작된다(팝업 차단에
      걸리지 않는지도 확인)
- [ ] 받은 `.ydchar.zip`을 [가져오기]로 다시 넣으면 새 캐릭터로 복원된다
      (원본을 덮어쓰지 않고 별개로 추가되는지도 확인)
- [ ] 일부러 망가뜨린 zip(예: 안에 있는 `manifest.json`을 지우거나, 확장자를
      `.exe`로 바꾼 파일을 넣거나, 압축 프로그램으로 손상시킨 파일)을
      넣었을 때 거부되고 이유가 화면에 뜬다(크래시하지 않는지 확인)

## 업로드 제한 (1-7B)
- [ ] 2048px(스탠딩) 또는 1024px(썸네일)보다 큰 이미지를 올리면 "자동으로
      줄여서 넣을까요?" 다이얼로그가 뜬다
- [ ] 자동 축소를 확인하면 이미지가 정상적으로 줄어들어 저장된다
- [ ] 픽셀은 정상인데 용량만 큰 이미지(예: 압축이 잘 안 되는 이미지)를
      올리면 자동 축소 제안 없이 거부 메시지만 뜬다
- [ ] 1MB보다 큰 보이스 파일을 올리면 거부 메시지가 뜬다
- [ ] WAV 파일을 올리면(한도 안이어도) OGG/MP3 변환을 권하는 메시지가 뜬다
- [ ] 편집 화면 상단의 "현재 캐릭터 용량" 표시가 파일을 추가/제거할 때마다
      바로 갱신된다
- [ ] 용량이 10MB를 넘으면 노란색, 15MB를 넘으면 빨간색으로 바뀐다
- [ ] 15MB를 넘겨도 저장 자체는 되고(막히지 않고), 전송이 안 될 수 있다는
      안내만 뜬다

## 브라우저 고유 문제
- [ ] **시크릿(프라이빗) 모드**에서 캐릭터를 만들거나 저장하면 "브라우저가
      저장을 막고 있어요. 캐릭터 팩으로 내보내서 보관하세요" 안내가 뜨고
      게임이 죽지 않는다(브라우저마다 IndexedDB 정책이 달라서 크롬/파이어폭스
      둘 다 확인하면 좋다)
- [ ] 게임 시작 직후(캐릭터 선택 화면 등에서 이미 한 번 클릭한 뒤이므로
      브라우저의 오디오 자동재생 차단에 걸리지 않아야 정상) "게임 시작 인사"
      보이스가 무음으로 씹히지 않고 들린다
- [ ] 캐릭터를 여러 번 바꿔가며 한동안(예: 10분 이상) 계속 플레이해도
      브라우저 탭의 메모리 사용량이 계속 우상향하지 않는다(브라우저 작업
      관리자나 개발자 도구의 메모리 탭으로 확인 가능하면 더 정확함)
- [ ] 브라우저 창 크기를 여러 번 바꿔도(특히 아주 작게/아주 넓게) 레이아웃이
      깨지거나 버튼이 겹치지 않는다 - 캐릭터 편집 화면과 게임 화면 둘 다 확인
- [ ] 화면 우하단의 디버그 버튼 6개가 창 크기를 바꿔도 항상 화면 안에
      온전히 보인다(이전에 잘리는 버그가 있었던 자리라 재확인 겸)

## 진행 중 발견 사항 메모
문제가 나오면 여기(또는 대화창)에 어떤 항목에서, 어떤 순서로 재현했는지,
브라우저 콘솔에 뭐라고 찍혔는지 적어서 알려주면 된다. "고쳤다"고 확신할 수
없는 항목은 다시 이 문서에 표시를 남겨서 다음에 이어갈 수 있게 한다.
